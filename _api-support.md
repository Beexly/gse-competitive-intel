# How do I request access to the FantasyPros API?

![Dan Martin](https://support.fantasypros.com/system/photos/52811106342939/daniel-martin-jr-headshot.png)



Dan Martin






-
Updated
19 hours ago

FantasyPros offers free, premium, and commercial API access options based on how you plan to use the data.

## Free API Access

Free access is available for personal, non-commercial use. It is intended for:

- Building and testing applications
- Learning how the API works
- Creating prototypes

Free access is limited to non-production use.

## Premium API Access

Premium API access is included with an active FantasyPros MVP or HOF subscription.

Premium access includes:

- Production access for personal, non-commercial applications
- Higher rate limits than the free version

Your FantasyPros subscription must remain active to maintain premium API access.

## Commercial API Access

A separate commercial agreement is required for uses that include:

- Paid applications or services
- Business or organizational use
- Data redistribution
- High-volume platforms
- Products or services that generate revenue

To discuss commercial API access, please [contact our sales team](mailto:support@fantasypros.com) and include a brief description of your project and expected usage.

## Additional Usage Requirements

FantasyPros API access is provided without any warranty or guarantee.

You may not use FantasyPros API data to build a product or service that directly competes with FantasyPros.

FantasyPros must also be credited when publishing research, analysis, or other work based on data obtained through the API.

## Player Images

Player image URLs included in player endpoints are licensed to FantasyPros by Sportradar, LLC.

These images are not included in your FantasyPros API license and should not be used without permission from Sportradar.

## Review API Options and Request Access

Review the available API access options:

[https://www.fantasypros.com/api-data/](https://www.fantasypros.com/api-data/)

Request or activate an API key:

[https://secure.fantasypros.com/api-keys/request/](https://secure.fantasypros.com/api-keys/request/)
