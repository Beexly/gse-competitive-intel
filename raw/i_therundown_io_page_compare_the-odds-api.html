TheRundown vs The Odds API

Sub-second updates. REST + WebSocket.

TheRundown delivers sub-second odds updates. WebSocket push is available on Ultra and higher. The Odds API uses REST polling, with documented 60-second pre-match and 40-second in-play refresh intervals for featured markets.

Free includes delayed pre-match REST data. WebSocket requires Ultra or above.

Public documentation checked September 6, 2026. The featured-market pre-match interval begins to shorten six hours before start time.

When to evaluate TheRundown

Start with your required markets, update path, and workload. These are the integration choices TheRundown documents.

  • Stream sub-second odds updates over WebSocket on Ultra and higher.
  • Request the documented main line with main_line=true.
  • Scope requests to canonical sport, market, and event IDs.
  • Measure returned data with X-Datapoints and the key’s usage headers.
  • Render prices through the documented V2 event, market, line, and price hierarchy.
  • Evaluate with a free API key, then select a plan for delay, history, and volume.
  • Use the Build with AI guide for API examples, the documentation MCP, and a local data MCP scaffold.
