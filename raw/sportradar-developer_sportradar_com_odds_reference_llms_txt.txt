## API Reference: Mapping API

- [Mapping API index](https://developer.sportradar.com/odds/reference/mapping-api/llms.txt): full category index
- [Mapping Overview](https://developer.sportradar.com/odds/reference/mapping-overview.md): Get started with Sportradar's Mapping API
- [Sport Competition Mappings](https://developer.sportradar.com/odds/reference/mapping-sport-competition-mappings.md): Get competition mappings for a sport. Returns mappings between external IDs and Sportradar competition/tournament IDs. Only returns competitions from providers configured for the API key.
- [Season Competitor Mappings](https://developer.sportradar.com/odds/reference/mapping-season-competitor-mappings.md): Get competitor mappings for a season. Returns mappings between external IDs and Sportradar competitor IDs (SRIDs). Only returns competitors from providers configured for the API key.
- [Sport Event Competitor Mappings](https://developer.sportradar.com/odds/reference/mapping-sport-event-competitor-mappings.md): Get competitor mappings for a sport event. Returns mappings between external IDs and Sportradar competitor IDs. Only returns competitors from providers configured for the API key. Results are paginated by competitors (not individual mappings). Competitors are sorted alphabetically by ID. Mappings within each competitor are sorted by bookmaker_id, then external_id.
- [Season Player Mappings](https://developer.sportradar.com/odds/reference/mapping-season-player-mappings.md): Get player mappings for a season. Returns mappings between external IDs and Sportradar player IDs (SRIDs). Only returns players from providers configured for the API key.  Results are paginated by players (not individual mappings). Players are sorted alphabetically by ID. Mappings within each player are sorted by bookmaker_id, then external_id.
- [Sport Event Player Mappings](https://developer.sportradar.com/odds/reference/mapping-sport-event-player-mappings.md): Get player mappings for a sport event. Returns mappings between external IDs and Sportradar player IDs (SRIDs). Only returns players from providers configured for the API key. Results are paginated by players (not individual mappings). Players are sorted alphabetically by ID. Mappings within each player are sorted by bookmaker_id, then external_id.
- [Competition Season Mappings](https://developer.sportradar.com/odds/reference/mapping-competition-season-mappings.md): Get season mappings for a competition. Returns mappings between external IDs and Sportradar season IDs. Only returns seasons from providers configured for the API key.  Results are paginated by seasons (not individual mappings). Seasons are sorted alphabetically by ID. Mappings within each season are sorted by bookmaker_id, then external_id.
- [Daily Sport Event Mappings](https://developer.sportradar.com/odds/reference/mapping-daily-sport-event-mappings.md): Get sport event (match) mappings for a specific sport and date. Returns mappings between external IDs and Sportradar sport event IDs. Only returns events from providers configured for the API key.
- [Season Sport Event Mappings](https://developer.sportradar.com/odds/reference/mapping-season-sport-event-mappings.md): Get sport event mappings for a season. Returns mappings between external IDs and Sportradar sport event IDs (SRIDs). Only returns sport events from providers configured for the API key.
- [Sport Event Mappings](https://developer.sportradar.com/odds/reference/mapping-sport-event-mappings.md): Get mappings for a single sport event. Returns mappings between external IDs and the Sportradar sport event ID. Only returns mappings from providers configured for the API key.
- [Change Log](https://developer.sportradar.com/odds/reference/mapping-change-log.md): Find all updates to Mapping v2
- [FAQs](https://developer.sportradar.com/odds/reference/mapping-faqs.md): Frequently asked questions on Mapping v2
