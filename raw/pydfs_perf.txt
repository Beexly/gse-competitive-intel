<span id="pydfs-lineup-optimizer-performance-and-optimization"></span><h1>Performance and Optimization<a class="headerlink" href="#performance-and-optimization" title="Permalink to this headline">¶</a></h1>
<div class="section" id="solvers">
<h2>Solvers<a class="headerlink" href="#solvers" title="Permalink to this headline">¶</a></h2>
<p>By default, the optimizer uses <a class="reference external" href="https://coin-or.github.io/pulp/index.html">pulp</a> library under the hood with a default solver that is free but slow.
You can change it to another solver that pulp supports.
Here is an example of how to change the default solver for GLPK solver:</p>
<div class="highlight-python notranslate"><div class="highlight"><pre><span></span><span class="c1"># install glpk: https://www.gnu.org/software/glpk/</span>
<span class="kn">from</span> <span class="nn">pulp</span> <span class="kn">import</span> <span class="n">GLPK_CMD</span>  <span class="c1"># You can find names of other solvers in pulp docs</span>
<span class="kn">from</span> <span class="nn">pydfs_lineup_optimizer.solvers</span> <span class="kn">import</span> <span class="n">PuLPSolver</span>

<span class="k">class</span> <span class="nc">GLPKPuLPSolver</span><span class="p">(</span><span class="n">PuLPSolver</span><span class="p">):</span>
    <span class="n">LP_SOLVER</span> <span class="o">=</span> <span class="n">GLPK_CMD</span><span class="p">(</span><span class="n">path</span><span class="o">=</span><span class="s1">&#39;&lt;path to installed glpk solver&gt;&#39;</span><span class="p">,</span> <span class="n">msg</span><span class="o">=</span><span class="kc">False</span><span class="p">)</span>

<span class="n">optimizer</span> <span class="o">=</span> <span class="n">get_optimizer</span><span class="p">(</span><span class="n">Site</span><span class="o">.</span><span class="n">DRAFTKINGS</span><span class="p">,</span> <span class="n">Sport</span><span class="o">.</span><span class="n">BASEBALL</span><span class="p">,</span> <span class="n">solver</span><span class="o">=</span><span class="n">GLPKPuLPSolver</span><span class="p">)</span>
</pre></div>
</div>
<p>Also, the library supports another solver library: <a class="reference external" href="https://www.python-mip.com/">mip</a>.
It can be faster in some cases, especially if you are using pypy (<a class="reference external" href="https://docs.python-mip.com/en/latest/bench.html">benchmark</a>).
For you using mip you should install it via pip: pip install mip.
After that you can replace pulp:</p>
<div class="highlight-python notranslate"><div class="highlight"><pre><span></span><span class="kn">from</span> <span class="nn">pydfs_lineup_optimizer.solvers.mip_solver</span> <span class="kn">import</span> <span class="n">MIPSolver</span>

<span class="n">optimizer</span> <span class="o">=</span> <span class="n">get_optimizer</span><span class="p">(</span><span class="n">Site</span><span class="o">.</span><span class="n">DRAFTKINGS</span><span class="p">,</span> <span class="n">Sport</span><span class="o">.</span><span class="n">BASEBALL</span><span class="p">,</span> <span class="n">solver</span><span class="o">=</span><span class="n">MIPSolver</span><span class="p">)</span>
</pre></div>
</div>
</div>
<div class="section" id="decrease-solving-complexity">
<h2>Decrease solving complexity<a class="headerlink" href="#decrease-solving-complexity" title="Permalink to this headline">¶</a></h2>
<p>Sometimes optimization process takes a lot of time to generate a single lineup.
It usually happens in mlb and nfl because all teams play on the same day and each team has a lot of players and the total
number of players used in optimization is &gt;100. In this case, a good approach is to remove from optimization players with
small fppg value and a big salary.</p>
<div class="highlight-python notranslate"><div class="highlight"><pre><span></span><span class="n">optimizer</span> <span class="o">=</span> <span class="n">get_optimizer</span><span class="p">(</span><span class="n">Site</span><span class="o">.</span><span class="n">DRAFTKINGS</span><span class="p">,</span> <span class="n">Sport</span><span class="o">.</span><span class="n">BASEBALL</span><span class="p">)</span>
<span class="n">optimizer</span><span class="o">.</span><span class="n">load_players_from_csv</span><span class="p">(</span><span class="s1">&#39;dk_mlb.csv&#39;</span><span class="p">)</span>
<span class="n">optimizer</span><span class="o">.</span><span class="n">player_pool</span><span class="o">.</span><span class="n">add_filters</span><span class="p">(</span>
    <span class="n">PlayerFilter</span><span class="p">(</span><span class="n">from_value</span><span class="o">=</span><span class="mi">5</span><span class="p">),</span>  <span class="c1"># use only players with points &gt;= 5</span>
    <span class="n">PlayerFilter</span><span class="p">(</span><span class="n">from_value</span><span class="o">=</span><span class="mi">2</span><span class="p">,</span> <span class="n">filter_by</span><span class="o">=</span><span class="s1">&#39;efficiency&#39;</span><span class="p">),</span>  <span class="c1"># and efficiency(points/salary) &gt;= 2</span>
    <span class="n">PlayerFilter</span><span class="p">(</span><span class="n">from_value</span><span class="o">=</span><span class="mi">2000</span><span class="p">,</span> <span class="n">filter_by</span><span class="o">=</span><span class="s1">&#39;salary&#39;</span><span class="p">),</span>  <span class="c1"># and salary &gt;= 3000</span>
<span class="p">)</span>
<span class="n">optimizer</span><span class="o">.</span><span class="n">player_pool</span><span class="o">.</span><span class="n">exclude_teams</span><span class="p">([</span><span class="s1">&#39;Seattle Mariners&#39;</span><span class="p">])</span>
<span class="k">for</span> <span class="n">lineup</span> <span class="ow">in</span> <span class="n">optimizer</span><span class="o">.</span><span class="n">optimize</span><span class="p">(</span><span class="mi">100</span><span class="p">):</span>
    <span class="nb">print</span><span class="p">(</span><span class="n">lineup</span><span class="p">)</span>
</pre></div>
</div>
</div>
</div>
