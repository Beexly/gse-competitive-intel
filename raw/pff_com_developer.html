PFF Developer API

PFF data, in your terminal

Query PFF player grades and Premium Stats Pro data programmatically with your PFF Pro subscription. No SDK to learn — install the Restish CLI, log in with your PFF account, and go.

Get startedBrowse the reference
Terminalzsh
$ brew install restish
$ restish api connect pff https://api.pff.com
$ restish pff passing --league nfl --season 2025 -f 'body.passing_summary[0]'
