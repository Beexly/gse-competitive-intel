Fixtures

Method

GET/POST api.api-tennis.com/tennis/?method=get_fixtures

Returns tennis fixtures included in your current subscription plan. Each match also includes pointbypoint, scores and statistics inline (empty arrays when not yet available) — no separate call is needed for a match's set scores or per-player statistics (aces, serve percentages, break points, etc.).

Parameters

Parameter Description
method API method name
APIkey Authorization code generated from your api tennis account
date_start Start date (yyyy-mm-dd)
date_stop Stop date (yyyy-mm-dd)
event_type_key Event Type Key - if set only matches from specific tennis event type will be returned (Optional)
tournament_key Tournament Key - if set only matches from specific tennis tournament will be returned (Optional)
tournament_season Tournament Season - if set only matches from specific tennis tournament season will be returned (Optional)
match_key Match Key - if set only details from specific tennis match will be returned (Optional)
player_key Player Key - if set only details from specific tennis player will be returned (Optional)
timezone The timezone where you want to receive the data in tz format (exemple: America/New_York). Default timezone: Europe/Berlin (Optional)

News

Method

GET/POST api.api-tennis.com/tennis/?method=get_news

Returns AI-synthesized tennis news articles about players, tournaments and matches. Available on the Ultra plan only.

An article is linked to every entity it's actually about — a single article can carry a player_key, a tournament_key and an event_key all at once (e.g. a match report is tied to the match itself, the tournament it's part of, and the featured player). Any of these three can independently be null if that dimension wasn't identified for the article. entity_type / entity_key are kept for backwards compatibility and just mirror the single most specific match reflected (priority: match > tournament > player).

Parameters

Parameter Description
method API method name
APIkey Authorization code generated from your api tennis account
player_key Player Key - returns news about this player, including match reports the player is involved in (Optional)
tournament_key Tournament Key - returns news about this tournament, including match reports from it (Optional)
match_key Match Key - returns the news article about this specific match, if one exists (Optional)
date_start Only return articles published on or after this date, format YYYY-MM-DD (Required)
date_stop Only return articles published on or before this date, format YYYY-MM-DD (Required)

Draw

Method

GET/POST api.api-tennis.com/tennis/?method=get_draw

Returns the tournament draw (bracket) for a given tournament and season - rounds, matchups, seeds and byes, plus each match's live result/status where already available. When the tournament's official draw has been published by our data provider, the response reflects that draw exactly ("source": "draw_feed"), including still-undecided future rounds as empty "TBD" slots that fill in automatically as each round is played. For tournaments where the official draw isn't available yet, the bracket is instead reconstructed from played/scheduled matches ("source": "reconstructed_from_results").

Parameters

Parameter Description
method API method name
APIkey Authorization code generated from your api tennis account
tournament_key Tournament Key - the tournament to return the draw for (Required)
tournament_season Tournament Season - defaults to the current year if not set (Optional)
include_qualification Set to 1 to also include qualification/wild-card brackets alongside the main draw (Optional)
timezone The timezone where you want to receive the data in tz format (exemple: America/New_York). Default timezone: Europe/Berlin (Optional)
