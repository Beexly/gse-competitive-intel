# OC Core Overview

## Introduction

**Odds Comparison Core** (OC Core) is an access tier for the Sportradar Odds Comparison v2 APIs. Rather than a separate API, it is a pipeline configuration applied at the API key level by Sportradar Support — providing access to the global Core Crawlers pipeline, as opposed to the US-focused Magic Crawlers pipeline available by default.

Once enabled, your OC Core key can be used with the <Anchor label="Prematch" target="_blank" href="https://developer.sportradar.com/odds/reference/oc-prematch-overview">Prematch</Anchor>, <Anchor label="Player Props" target="_blank" href="https://developer.sportradar.com/odds/reference/oc-player-props-overview">Player Props</Anchor>, <Anchor label="Live Odds" target="_blank" href="https://developer.sportradar.com/odds/reference/oc-live-odds-overview">Live Odds</Anchor>, and <Anchor label="Futures" target="_blank" href="https://developer.sportradar.com/odds/reference/oc-futures-overview">Futures</Anchor> endpoints to return data from **140+ global bookmakers** across a broad range of sports and competitions.

OC Core is well-suited for:

* Global bookmaker coverage beyond the US market
* Broader sport availability, including niche and regional sports
* Migration from the Odds Comparison Regular (v1) product

## Getting Access

OC Core access is configured by Sportradar Support at the API key level. To get started, reach out to our support team to have Core enabled on your account.

<Callout icon="🙋‍♂️" theme="default">
  ### Need assistance?

  Contact our 24/7 Support team ([mediasupport@sportradar.com](mailto:mediasupport@sportradar.com)) to enable OC Core on your API key.
</Callout>

<br />

### Identifying Your Access Level

Each OC API response returns an `X-Origin-Id` header that identifies the bookmaker pipeline your key is configured for:

| `X-Origin-Id` Value            | Access Level |
| :----------------------------- | :----------- |
| `MARKET_ORIGIN_CORE_CRAWLERS`  | OC Core Key  |
| `MARKET_ORIGIN_MAGIC_CRAWLERS` | OC US Key    |

## OC Core vs. OC US

OC Core and OC US share the same API structure but draw from different bookmaker pipelines, resulting in meaningful differences in coverage, depth, and consistency.

| Area                | OC US                                                            | OC Core                                                                     |
| :------------------ | :--------------------------------------------------------------- | :-------------------------------------------------------------------------- |
| **Default Access**  | Yes                                                              | No — configured by Sportradar Support                                       |
| **Ingest Source**   | Magic Crawlers                                                   | Core Crawlers                                                               |
| **Coverage Model**  | Fixed                                                            | Broad, feed-driven                                                          |
| **Bookmakers**      | US-focused set                                                   | 140+ global bookmakers                                                      |
| **Sports**          | Limited, curated set                                             | 30+ global and niche sports                                                 |
| **Markets**         | Fixed and standardized                                           | Supported list; event/feed dependent                                        |
| **Player Props**    | Extensive                                                        | Limited (Soccer goalscorer only)                                            |
| **Latency**         | Lower and more predictable                                       | Variable                                                                    |
| **Consistency**     | High                                                             | Variable                                                                    |
| **Recommended for** | US bookmaker comparison, lower latency, predictable integrations | Global bookmaker coverage, OC Regular migration, broader sport availability |

Although OC Core has broader bookmaker and sport coverage, it does not guarantee parity with OC US — particularly around player props depth, event coverage, feed refresh timing, and bookmaker market depth.

### MCP Server

The **Sportradar Odds Comparison MCP Server** is a Model Context Protocol (MCP) implementation that bridges AI assistants directly to our Odds Comparison API feeds. It allows LLMs to use standardized tools to fetch our sports data, helping to power your applications, assist in coding, and streamlining your integration.

For detailed instructions on how to set up and use this integration, visit our <Anchor label="MCP Server" target="_blank" href="https://developer.sportradar.com/getting-started/docs/mcp-server">MCP Server</Anchor> documentation.
