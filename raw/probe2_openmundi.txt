<h2 id="whatis">What’s <code>world.db</code>?</h2>

<p>A free open public domain world database ‘n’ schema
for use in any (programming) language (e.g. uses plain text datasets).</p>

<h2 id="webadmin">Web Admin Site</h2>

<p>Try the <code>world.db</code> web admin app running
on Heroku <a href="http://worlddb.herokuapp.com"><code>worlddb.herokuapp.com</code></a>.</p>

<h2 id="real-world-usage">Real World Usage</h2>

<p><a href="https://github.com/geraldb/world.db.admin">world.db.admin</a> - A free, open source web admin tool for world.db in Ruby on Rails (version 3.2 and up).</p>

<p><a href="https://github.com/opensport">sport.db</a> - free open public domain sports database &amp; schema.</p>

<p><a href="https://github.com/openfootball">football.db</a> -  free open public domain football (soccer) database &amp; schema</p>

<p><a href="https://github.com/opensport/formula1.db">formula1.db</a> - free open public domain Formula 1/Formula One database &amp; schema</p>

<p><a href="https://github.com/opensport/ski.db">ski.db</a> -  free open public domain ski alpin/alpine ski database &amp; schema</p>

<p><a href="https://github.com/openbeer">beer.db</a> - free open public domain beer database &amp; schema</p>

<p><a href="https://github.com/openbookie/sportbook">Sportbook</a> - free, open source sports betting (prediction) pool
in Ruby on Rails (version 3.2 and up). </p>
